info 기능 설명

이 제스처는 SignBridge 앱에서 수어 번역 세션을 시작하는 명령어입니다. 번역을 시작하고 싶을 때 카메라를 향해 이 동작을 명확하게 보여주세요.

format_list_numbered 동작 방법

  1. 1

    준비 자세

    가슴 높이에서 양손을 가볍게 듭니다. 카메라 렌즈와 정면이 되도록 위치를 잡습니다.

  2. 2

    손가락 펴기

    양손의 집게손가락(검지)만 곧게 펴고, 나머지 손가락은 가볍게 쥡니다.

  3. 3

    맞대기

    펼친 두 집게손가락의 끝을 서로 가볍게 맞댑니다. 약 2초간 유지하여 앱이 인식할 수 있도록 합니다.
