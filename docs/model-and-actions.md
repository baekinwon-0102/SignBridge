# 수어 모델 교체와 명령 실행

현재 모델은 assets/models/sign_language_five_words.pth의 v2 체크포인트다.
앱은 변환된 sign_language_five_words.onnx를 사용하며, 공통 설정은 assets/models/sign_model.json이다.

| 클래스 | 단어 | 실행 기능 |
| --- | --- | --- |
| 0 | 아프다 | 119 전화 앱 발신 화면 |
| 1 | 위 | 미디어 볼륨 한 단계 올리기 |
| 2 | 아래 | 미디어 볼륨 한 단계 내리기 |
| 3 | 회사 | 등록한 회사로 네이버맵 대중교통 길찾기 |
| 4 | 엄마 | 연락처 이름이 정확히 엄마인 번호로 전화 |

## 모델 입력과 변환

- 입력: float32 [1, 30, 452], 텐서명 features.
- 출력: float32 [1, 5] logits, 텐서명 logits. softmax 확률로 신뢰도를 계산한다.
- 프레임별 입력: 어깨 정규화 기본 특징 150개, 속도 150개, 가속도 150개, 오른손·왼손 감지 마스크 2개.
- 30프레임 안의 누락된 손 특징을 선형 보간하고, 앞뒤 끝은 가장 가까운 감지 프레임 값으로 채운다.
- 첫 프레임 속도와 가속도는 0이다. 감지 마스크는 원래 감지 여부를 유지한다.
- Android SignTemporalFeatures와 웹 buildTemporalFeatures를 assets/modules/features.py의 기준 결과와 비교 테스트한다.

python tools/export_sign_model.py는 체크포인트의 구조·클래스 순서를 검증하고
ONNX·라벨 맵·한국어 사전·앱 설정·검증 보고서를 생성한다.
PyTorch와 ONNX의 출력과 최상위 클래스가 일치하는지 확인한다. 변환 후 앱을 다시 빌드해야 한다.

## 인식과 실행

신뢰도 75% 이상에서 5개 단어의 기능을 자동 실행한다.
표시용 정수 확률은 버림 처리하여 74.9%가 75%로 반올림되어 실행되지 않게 한다.
새 단어는 버튼 없이 바로 실행한다. 같은 단어의 연속 프레임은 중복 실행하지 않는다.
손이 0.8초 이상 감지되지 않으면 같은 단어도 다시 실행할 수 있다.
앱 복귀 후에는 자동 실행을 계속하며, 다시 인식하기 버튼은 수동 초기화용이다.
Android와 웹은 번역 문구와 별도로 handsAbsent 신호를 전달한다. 모델 로딩·수집 문구는 손을 내린 것으로 취급하지 않는다.
개발자 모드에서는 5개 단어 버튼을 사용하고 카메라 자동 실행을 중지한다.
추론 간격은 최소 500ms이며 최초 30프레임 수집 시간이 별도로 필요하다.

회사 위치는 이름과 위도·경도를 등록한다. 엄마 전화는 연락처·전화 권한이 필요하다.
119는 전화 앱에서 통화 버튼을 눌러 발신한다.
웹은 전화 앱과 지도 연결 요청을 지원하며, 연락처 조회와 시스템 볼륨 제어는 Android에서 지원한다.
iOS 네이티브 동작은 구현되어 있지 않다.

## 검증

Flutter 테스트는 플랫폼 호출을 대체하여 75% 미만 거부, 75% 허용,
5개 기능 연결과 중복 실행 방지를 확인한다. 실제 전화를 걸지 않는다.
Java·웹 테스트는 Python의 기본 특징과 시간 특징을 비교한다.
모델 변환 검증만으로 실제 수어 인식 정확도를 확인할 수는 없다.
실기기에서는 5개 단어의 영상과 연락처 권한, 지도 실행, 볼륨 변경을 확인한다.
119는 실제 발신 없이 발신 화면까지만 확인한다.
